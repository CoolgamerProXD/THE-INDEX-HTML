## ⚔️ HTML Expeditions

**HTML Expeditions** is a 3D browser-based fan game inspired by the Roblox game *Anime Expeditions*. It's built entirely with WebGL, runs from a single HTML file, and needs zero setup.

### What's in it so far:
- 3D lobby with WASD movement, sprint, jump, and mouse-look
- Full battle system with units, upgrades, and selling
- Summon system with 5 distinct presentation tiers (Rare through Secret)
- Colour Mode toggle for visual vibes
- Camera freedom with smooth easing, orbit, tilt, and zoom
- Fully offline, self-contained in one HTML file

### Current status: 🚧 HEAVILY work in progress

This is very much still being built. Things will change, break, get reworked, or disappear entirely between versions. If you grab it now, you're getting a snapshot of something unfinished. That said, it's playable and I think it's pretty fun already.

**Download the current WIP:** Check the `games/html-expeditions/` folder for the latest zip.
